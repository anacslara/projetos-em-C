## 💻 Projetos em C
Este repositório reúne exercícios e projetos desenvolvidos durante a faculdade utilizando a linguagem C
Os exercícios vão desde conceitos mais básicos até conteúdos mais avançados da programação

## 🛠️ Temas abordados:
* **Lógica de programação:** resolução de problemas com raciocínio estruturado
* **Estruturas condicionais e repetição:** uso de `if`, `for`, `while`, etc
* **Vetores e variáveis:** manipulação de dados básicos
* **Structs:** organização de informações em estruturas
* **Arquivos binários:** leitura e escrita de dados em arquivos (incluindo um módulo dedicado só a isso)
